THE SHORT VERSION
A clear path from
config to ready.
ServiceBoot runs local processes in dependency order. No containers, no guessing.
  1. 01
    Choose a configuration
    Your YAML describes commands, dependencies, and how to check readiness. Add a .yml file to samples/ or the repo root, then refresh. Use letters, digits, underscores, or hyphens in the filename.
  2. 02
    Pick a startup strategy
    Sequential starts one at a time. Parallel starts each level together. Adaptive selects parallel when graph width is greater than twice its depth.
  3. 03
    Start, observe, stop
    Follow real readiness events and logs. Stop shuts down dependents first, then their dependencies. Closing this browser tab leaves services running; stop them here or with the CLI.
Benchmark results are saved measurements from the report, not live CPU or memory readings.
